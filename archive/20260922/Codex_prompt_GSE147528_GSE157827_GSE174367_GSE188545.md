### 5. 一手资料核验与下载清单

对每个 GSE 执行以下动作：

1. 用 NCBI GEO 官方页面、GEOquery family/SOFT/MINiML、GSM 页面和论文补充材料核对：

   - 10x chemistry、Cell Ranger 版本、reference genome/GTF；

   - matrix 是 raw/unfiltered 还是 filtered；
   - 每个 supplementary file 的准确 URL、大小和用途。
2. 生成 `metadata/file_manifest.tsv`，至少包含：

3. 生成 `metadata/source_provenance.tsv`，逐字段记录元数据来源和访问日期。
4. 若一个 Series 混有其他 assay，只下载目标 snRNA gene-expression 文件。严禁误下载 snATAC、bulk RNA 或整套无关 SRA runs。

针对四个队列特别检查：

- **GSE147528**：预计为 20 个 library（同一批 donor 的 EC 与 SFG）。逐一确认 H5 是否为 `raw_gene_bc_matrices`，不能把 raw droplet matrix 当作作者 QC 后的 filtered cells。核实 barcode 是否会在不同 library 间重复。

- **GSE174367**：确认 Series-level H5 与 cell metadata 的准确文件名；验证 cell metadata 能否从聚合矩阵 barcode 唯一恢复 donor、condition 和 sample。不要下载同 Series 的 snATAC 部分。
- **GSE188545**：确认 12 位 donor 的三件套是否齐全；兼容 `genes.tsv` 与 `features.tsv` 两种命名。

### 7. 矩阵读取与原始数据验证

为每个 library 或可恢复的 sample 建立稀疏 AnnData/SingleCellExperiment 对象，保留整数 UMI counts。

每个对象必须检查并报告：

- matrix 维度、稀疏度、非零元素数；
- count 是否为非负整数；
- barcode 是否唯一；
- feature ID、gene symbol 和 feature type 列结构；
- 是否混有 Antibody Capture/ATAC 等非 Gene Expression feature；
- metadata barcode 与 matrix column 的一一对应率；
- 预期 donor/library 数与实际数；
- 每个 sample 的 nuclei/droplet 数、总 UMI 和检测基因分布。

任何 metadata 对齐不得只依赖行顺序，必须用显式 barcode/library key 连接。若 GSE174367 barcode 在不同 library 中可能重复，先确认聚合文件采用了何种 suffix 或 sample key，再建立唯一 ID；不能用 `match()` 后忽略重复和缺失。

### 8. Raw 与 filtered matrix 的差异处理

不得对 raw 和 filtered matrix 使用完全相同的入口流程：

1. 如果 GSE147528 的 H5 确为 raw droplet matrix：
   - 逐 library 运行 empty-droplet/cell-calling（优先 `DropletUtils::emptyDrops`，结合 knee/inflection diagnostics）；
   - 生成 barcode-rank plot；
   - 不得仅用一个固定 UMI 阈值代替 cell calling；
   - 保存 cell-calling 参数和入选 barcode。
2. 对作者提供的 filtered matrices：
   - 不重复把其当 raw droplets 做 EmptyDrops；
   - 仍执行核级 QC、doublet 检测和离群诊断。
3. 如果能获得作者 QC barcode/metadata，则比较自建 cell calling 与作者集合的一致率，但不静默混用两套标准。

### 9. 逐 library 自适应 QC

QC 必须先按 library/sample 独立完成，不能四个数据集合并后使用一个固定阈值。至少计算：

- `total_counts/nCount_RNA`
- `n_genes_by_counts/nFeature_RNA`
- mitochondrial fraction
- ribosomal fraction
- hemoglobin fraction（用于污染诊断）
- top genes fraction
- complexity：`log10(genes)/log10(UMI)` 或等效指标

使用每个 library 的分布、log-scale median/MAD、knee plot 和 scatter plot生成建议阈值。可以设置保守的绝对下限防止空滴进入，但最终阈值需在 `tables/qc_thresholds_by_library.tsv` 中逐 library 明示，且说明规则。不要机械套用所有样本统一的 `nFeature > 500` 或 `percent.mt < 5%`。

输出过滤前后每个 library 的：

- nuclei 数；
- median genes、UMI、mitochondrial fraction；
- 各过滤原因及数量；
- QC violin/scatter/barcode-rank 图；
- 按 dataset、condition、region 汇总的保留率。

### 10. Doublet 与 ambient RNA

1. doublet detection 必须逐 10x library 运行，不能在 merge 后运行。
2. 优先采用 `scDblFinder`；若全流程以 Python 为主，可使用 Scrublet，但需保存 score、阈值和每个 library 的预期/实际 doublet rate。
3. 小样本或细胞数过低导致算法不稳定时，标记为 `doublet_status_uncertain`，不得无说明强行过滤。
4. 对各数据集生成 ambient RNA diagnostics。只有具备 raw droplet matrix 和可靠 empty-droplet background 时才正式使用 SoupX/CellBender；只有 filtered matrix 时不得声称完成了可靠 ambient correction。
5. 如果需要 ambient correction，保存未校正和校正 counts 两套对象，并说明后续哪一层用于何种分析。

### 11. 基因标识统一：建立双轨数据对象

必须建立两条相互独立的数据轨道：

#### A. Native-count 统计轨道

- 保留每个 dataset 原始 gene ID、gene symbol 和整数 UMI counts。
- 用于 dataset 内 donor-level pseudobulk、DE 和后续 meta-analysis。
- 不因为另一个数据集缺失某基因就把它填零后用于跨队列 pooled DE。

#### B. Harmonized integration 轨道

- 优先使用去掉版本号后的 Ensembl gene ID 进行跨队列映射。
- 保留 `ensembl_id_original`、`ensembl_id_stripped`、`gene_symbol_original`、`gene_symbol_current`、mapping source/version。
- 对一对多或多对一映射出具冲突表；不得凭 symbol 静默合并不同 Ensembl genes。
- 为 scVI/聚类建立四队列共享、可核验的 gene universe。可使用共同高变基因或明确共享基因集；把选择过程和基因数写入报告。
- 对“某数据集因注释版本不存在的基因”不得简单解释为真实零表达。

输出：

- `metadata/gene_crosswalk.tsv`
- `reports/gene_harmonization_report.md`
- 每队列 native-count object
- 一个 harmonized integration object

### 12. Normalization、降维与 scVI 整合

1. 原始 counts 始终保存在 `.layers["counts"]` 或等效 slot。
2. log-normalized 数据只用于探索性绘图和 marker 浏览，不替代原始 counts。
3. 四队列联合参考图谱优先使用 scVI：
   - 输入为整数 raw counts；
   - `batch_key` 优先设为 `dataset`，并评估 `library_id` 作为 batch 的敏感性分析；
   - chemistry 可作为 categorical covariate；
   - **不得把 condition、Braak、region 作为要校正掉的 batch covariate**；
   - 不建议默认把 donor 作为 batch，因为 donor 与 disease 可能部分共线；如尝试，必须作为敏感性分析而非唯一结果。
4. 保存随机种子、训练/验证 loss、epoch、GPU/CPU配置、模型目录和 latent representation。
5. 如显存或内存不足：
   - 使用合理 mini-batch；
   - H5AD/Zarr backed storage；
   - 先用每个 major cell type 分层训练；
   - 不得把矩阵 densify。
6. 至少评估以下整合质量：
   - 按 dataset、condition、region、donor、chemistry、major cell type 上色的 UMAP；
   - dataset mixing 与生物学 label conservation；
   - 每个 cluster 的 dataset/condition/region 构成；
   - iLISI/cLISI、kBET 或 scIB 中资源允许的指标；
   - “是否过度校正掉 disease/region signal”的定性和定量检查。

scVI latent space 只服务于邻居图、UMAP、聚类、label transfer 和 cell-state alignment，不用于直接生成疾病差异表达的 p 值。

### 13. 细胞类型注释

先完成 major cell type 注释，再对关键谱系单独重聚类。注释必须结合：

- 经典 marker；
- 各研究作者原始注释（若有）；
- cluster-level differential markers；
- 必要时使用公开脑细胞参考图谱进行 reference mapping。

至少考虑：Excitatory neuron、Inhibitory neuron、Astrocyte、Oligodendrocyte、OPC、Microglia、Endothelial、Pericyte/VSMC、Ependymal、Immune 等。不得仅根据单一 marker 自动命名。

输出原始作者标签、统一 major label、细分 label、注释证据和置信度。对低质量/疑似 doublet/无法判断 cluster 保留 `Unknown/Ambiguous`，不要强行归类。

### 14. Pseudobulk 和统计分析准备

差异表达的统计单位必须是 donor，不是 nucleus。

1. 按 `dataset × region × donor_global × cell_type` 汇总原始 UMI counts。
2. 设置最低纳入门槛并做敏感性分析，例如每个 donor-cell type 至少 20、30 或 50 nuclei；阈值必须在配置中可修改，并报告每种阈值的 donor 保留情况。
3. 输出每个 cell type 的 gene × pseudobulk-sample integer count matrix、sample metadata 和有效 library size。
4. 低表达过滤、TMM normalization、dispersion estimation 和模型设计在 edgeR/dreamlet 中完成。

主要比较：

- GSE157827：PFC，AD vs Control，dataset 内分析。
- GSE174367：PFC，AD vs Control，dataset 内分析。
- GSE188545：MTG，AD vs Control，作为外部验证。
- GSE147528：
  - Braak VI vs Braak 0；
  - Braak 0 → II → VI 的有序趋势；
  - EC 与 SFG 分层分析；
  - 若进行联合脑区模型，必须纳入 donor 配对/随机效应及 `Braak × Region`。

协变量只在数据完整、样本量允许且不产生秩亏时加入。候选包括 age、sex、PMI、RIN，但每个模型都必须先生成 design matrix rank 和共线性诊断。不得为了形式完整而在小样本模型中堆入过多协变量。

### 15. PFC 联合分析与跨队列 meta-analysis

同时提供两种互补结果：

1. **PFC pooled pseudobulk 敏感性分析**：仅 GSE157827 + GSE174367，在同一 cell type 内使用包含 `condition + dataset` 的模型；如有必要考虑 donor/sample结构。先确认 condition 在每个 dataset 内均有重复，且设计矩阵满秩。
2. **首选的分队列效应估计 + meta-analysis**：
   - 每个 dataset/region 分别估计 logFC、SE、P 和 FDR；
   - 对匹配 cell type 和 gene 做 fixed-effect 与 random-effects meta-analysis；
   - 报告异质性 Q、I²、tau²；
   - 优先标记跨队列方向一致、meta-FDR 显著、并在外部脑区复现的基因/模块。

### 16. 细胞组成分析边界

如进行 cell-type proportion 分析：

1. 以 donor/library 为单位，不能把 nucleus 当重复。
2. 分 dataset、region 建模；不能把不同脑区的比例直接混作同一总体。
3. 考虑 compositional nature，可使用 propeller、scCODA 或等效方法。
4. 明确说明捕获效率、解离/核提取流程、QC 和采样深度会影响细胞比例。
5. scVI 后的 cluster 混合良好不代表原始细胞比例可无偏跨研究比较。
