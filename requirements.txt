# PTM2CellNet dependency index (P1-2).
#
# The default install now pulls in ONLY the minimal core (CNN/Transformer
# train + predict + API). Heavy / CUDA-sensitive capabilities are split into
# their own files so a clean CPU environment can run the E2E loop without
# fighting optional build chains:
#
#     pip install -r requirements-core.txt        # minimal E2E (recommended)
#     pip install -r requirements-pretrained.txt   # + ESM-2 / ProtBERT
#     pip install -r requirements-mamba.txt        # + Mamba encoder (CUDA)
#     pip install -r requirements-analysis.txt     # + scVI / sspa analysis
#
# For backwards compatibility this top-level file aggregates core + pretrained
# + lightning, matching what existing CI/developer environments had. Docker and
# clean-environment jobs should prefer ``requirements-core.txt``.

-r requirements-core.txt
-r requirements-pretrained.txt
