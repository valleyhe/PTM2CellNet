## 2. 总体结论

当前项目已经不是“蓝图未落地”的早期状态。核心数据、模型、训练、评估、API、DAVF、GenKI/PTM 虚拟扰动和可观测性模块均有实代码和测试覆盖。与 v8 报告相比，部分旧缺口已经被本次提交或既有代码消除:

- 公共 PTM 数据库加载已经存在: `DataLoader` 通过多继承组合 `PTMDatabaseLoaderMixin`，并提供 `load_from_phosphositeplus()`、`load_from_dbptm()`、`load_from_cplm()`。[src/data/loaders/loader.py:11](../src/data/loaders/loader.py#L11), [src/data/loaders/ptm_database_loaders.py:18](../src/data/loaders/ptm_database_loaders.py#L18), [src/data/loaders/ptm_database_loaders.py:102](../src/data/loaders/ptm_database_loaders.py#L102), [src/data/loaders/ptm_database_loaders.py:142](../src/data/loaders/ptm_database_loaders.py#L142)
- 取消范围已明确登记: 实时质谱流、自定义 PTM 数据库、GUI、API key 功能扩展被列入 `CANCELLED_FEATURES`，不应再作为路线图目标。[src/models/roadmap.py:80](../src/models/roadmap.py#L80)
- `/metrics` 已输出 Prometheus text exposition，并保留 JSON fallback。[src/api/monitoring.py:47](../src/api/monitoring.py#L47), [src/api/monitoring.py:70](../src/api/monitoring.py#L70), [src/api/monitoring.py:130](../src/api/monitoring.py#L130)
- DAVF API 输入已经包括 `PTMSite.gene_symbol` 和 `PredictionRequest.use_davf`，预测预处理会生成 `davf_sites` / `davf_gene_names`。[src/api/schemas.py:13](../src/api/schemas.py#L13), [src/api/schemas.py:62](../src/api/schemas.py#L62), [src/api/routes/predictions.py:366](../src/api/routes/predictions.py#L366)

但项目仍存在 4 类重要问题:

1. 若干“看似实现”的功能实际仍是半成品或兼容 shim，尤其是 DAVF 端到端微调、分布式训练、ESM-3 真实能力、外部结构工具 fallback。

## 5. 高严重度问题详细解决策略

### 5.1 `/initialize` API key timing-safe 修复

修改范围:

- `src/api/routes/initialize.py`
- `tests/unit/test_api_routes.py` 或新增 `tests/unit/test_initialize_auth.py`

实施步骤:

1. 在 `initialize.py` 引入 `import hmac`。
2. 将 `if x_api_key != expected:` 替换为:

```python
if not hmac.compare_digest(str(x_api_key), str(expected)):
    raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Invalid API key")
```

3. 测试 missing header 返回 401、wrong key 返回 403、correct key 允许继续。
4. 加一条 monkeypatch 测试，确认 `hmac.compare_digest` 被调用，防止回归为普通比较。

### 5.2 mypy 基线恢复

建议拆成 4 个阶段:

1. 依赖/stub 阶段: 增加 `types-requests`、`types-PyYAML`，修复 unused ignore。
2. DataLoader 阶段: 为 mixin 定义 `_DataLoaderProtocol`，让 `PTMDatabaseLoaderMixin` 的工具方法在类型层面可见。
3. Dataset 阶段: 把 `_DatasetConfig` 和 `PTMDatasetBase` config 类型统一成 `Mapping[str, Any]` 或 dataclass。
4. API/GenKI 阶段: 修复 `PredictionResponse` alias、GenKI adapter forward return type、monitoring YAML import。

完成标准:

```bash
mypy src
```

结果应为 0 errors，且不重新引入 `mypy: ignore-errors`。

### 5.3 DAVF E2E 微调脚本完成

当前脚本必须二选一:
