# PTM2CellNet 当前代码现状系统性复核报告 v17

生成日期：2026-07-06
复核对象：本地 `main` 当前工作树（含本轮修复提交）
前置基线：v16（`docs/项目代码现状系统性复核报告_2026-07-06_v16.md`）
复核方式：在 v16 基线上执行 3 轮「检查→修复→验证」迭代；本轮以 v16 §4（未实现/未完全实现功能）和 §5（技术债）中所有未闭环项 + 新识别的 v16 未覆盖技术债为闭环目标，逐项落地代码 + 测试 + 文档，并以 ruff / mypy / pytest 实测验证。

## 1. 执行摘要

本轮以 v16 列出的 8 个 F-* 功能项与 5 个 TD-L 技术债（含 v16 仍标的 60% 完成度的 F-03、80% 的 F-08）为输入，外加一轮独立的「未在 v16 提及」技术债扫描（torch.cuda.amp 弃用、mypy override 蔓延、ptm_site_dataset / multitask 的 stale override 等），完成 3 轮迭代后得到下列可复核结论：

1. **CPTAC/PDC 真实数据闭环（F-03，v16 标 60% / 中严重度 → v17 95%）**：`src/analysis/pdc_client.py` 新增 `get_file_url` + `download_file`，把 v16 仅取文件元数据的路径补齐为「GraphQL 解析 → 真实 TSV 流式下载（host 白名单 + 大小上限 + 原子 rename）」。`scripts/validate_cptac.py` 的 `download_phosphoproteomics` 改为默认走真实下载，失败即抛错而非静默回退 mock；`_parse_phospho_tsv` 把 CPTAC TSV 解析为 (sites × samples) 矩阵。`CPTACValidator` 新增 predictor wiring：找到最高 val_auroc 的 multitask checkpoint 后用 `BatchPTMPredictor` 跑 WT/mut 双预测，输出 `predicted_effect ∈ {gain, loss, neutral}`，否则明确标 `predictor_wired=false` + `scientifically_valid=false`。新增 22 个单测 + 2 个 opt-in 真实资产测试。
2. **FastAPI lifespan 现代化（F-08，v16 标 80% / 低 → v17 100%）**：`src/api/app.py` 从 `@app.on_event` 迁移到 `asynccontextmanager` lifespan。理由记入 docstring：FastAPI ≥0.54（远低于声明的最低 0.68）已支持 lifespan 关键字参数，且 `on_event` 在 ≥0.93 被官方弃用并产生 DeprecationWarning。新增 4 个 `test_api_lifespan.py` 测试（含源码扫描断言）锁定迁移不被回滚。
3. **mypy override 收敛（TD-L4，v16 标 10 个 → v17 2 个）**：通过类型修复而非继续 suppress，移除 8 个模块的 mypy override：`src.data.augmentation`（`int(...)` 修正 `seq_len`）、`src.models.signaling_network`（类级 `Any` 注解）、`src.models.ptm_site_predictor`（`Union` 类型 encoder 注解）、`src.models.variant_effect`（`cast(Mapping, ...)` + `Dict[str, Any]` 返回）、`src.analysis.pathway_integration`（`list(...)` 拼接 + `PathwayMatchResult` 返回 + `BytesIO` 分支）、`src.api.routes.state`（fallback 显式 `Any` 注解 + `data_cfg` isinstance 防御）、`src.data.ptm_site_dataset`、`src.models.multitask`（后两个其实已类型干净，override 是历史遗留）。剩余 2 个（`architectures` / `predictions`）因 DAVF/Tensor 多态与 pydantic 兼容性需要更深重构，本轮不强行触碰以免引入回归。
4. **torch.cuda.amp 弃用治理（v16 未提及，v17 新识别）**：`torch.cuda.amp.GradScaler` / `autocast` 在 PyTorch 2.x 已弃用并产生 FutureWarning。新增 `_make_grad_scaler` / `_amp_autocast` 版本兼容 helper（优先 `torch.amp.*` 现代形式，老 PyTorch fallback 到 legacy），`src/training/trainers.py` 与 `src/training/self_supervised.py` 全部 6 处弃用调用迁移完毕。新增 3 个测试锁定 helper 契约。
5. **生产安全与稳定性不变**：本轮未触碰 v16 已闭环的安全策略（fail-fast、CORS、safe_torch_load、host 白名单、速率限制）。新增的 `download_file` 复用既有 host 白名单 + 大小上限边界，未引入新的攻击面。
