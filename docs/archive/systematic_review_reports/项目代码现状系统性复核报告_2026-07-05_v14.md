## 5. 技术债分类

### 5.1 阻塞性 / 高严重度

| ID | 分类 | 问题 | 影响 | 解决策略 |
|---|---|---|---|---|
| TD-H1 | 工具链一致性 | `python -m mypy` 通过，但裸 `mypy` 使用 `/home/scu/.local/bin/mypy`，与当前 Python 环境不一致并报 25 条错误 | 开发者/CI 若调用不同 mypy 入口，会得到相互矛盾的质量结论 | 文档和 CI 固定使用 `python -m mypy`；可在 Makefile/CI 中显式 `which python && python -m mypy --version`；清理或避免使用用户级 `~/.local/bin/mypy` |
| TD-H2 | ESM-3 真实资产 | 依赖和 mock 测试已齐，但真实权重/缓存/账号/网络路径未验证 | 新环境可能通过单测但生产加载失败 | 增加 opt-in CI job 或手动验证脚本：检查 `ESM_DATA_DIR`、下载/加载 small open 权重、跑 1 条短序列 forward；失败时记录 `model_source` 和 cache path |
| TD-H3 | DAVF E2E 生产可信度 | 脚本已转正，但没有真实 checkpoint + 标注数据的 subprocess smoke | 训练入口可维护性和科学有效性仍未完全证明 | 增加小型 synthetic DAVF checkpoint fixture 或 mock subprocess；再增加真实数据手动验收命令与 artifact manifest 校验 |
