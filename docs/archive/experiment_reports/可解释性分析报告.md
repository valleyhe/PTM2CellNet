# PTM2CellNet 可解释性分析报告

**报告日期**：2026-06-30  
**目标**：阐述 PTM2CellNet 的可解释性分析流程，包括 PTM 位点重要性评分、两阶段筛选解释、信号通路映射、PTM 扰动方向映射以及 PTM 虚拟扰动对比。

## 1. 可解释性流程概览

```text
输入样本（sequence + ptm_sites）
    │
    ▼
┌─────────────────────────────┐
│ LeaveOnePTMOutScorer        │  ← 逐位点掩码，计算目标类别概率下降 Δp

└─────────────────────────────┘
    │
    ▼

    │
    ▼
┌─────────────────────────────┐
│ TwoStageExplanationPipeline │  ← 将高影响位点映射为基因扰动请求

└─────────────────────────────┘
    │
    ▼

│   · apply_soft_perturbation │
│   · node_decay / edge_scale │
└─────────────────────────────┘
```

## 2. LeaveOnePTMOutScorer：PTM 位点重要性评分

### 2.1 实现位置

- `src/evaluation/explainers.py::LeaveOnePTMOutScorer`

### 2.2 算法原理

对输入样本中的每个 PTM 位点执行“留一掩码”：

1. **基线预测**：在完整 PTM 集合上运行前向传播，记录目标类别概率 `p_base`。
2. **扰动预测**：掩掉当前 PTM 位点，重新前向传播，得到目标类别概率 `p_drop`。
3. **重要性得分**：`Δp = p_base - p_drop`。
4. **排序**：按 `Δp` 降序排列，得到对目标细胞状态贡献最大的 PTM 位点。

### 2.3 关键接口

| 方法 | 说明 |
|------|------|
| `rank_row(model, row)` | 对单行 DataFrame 进行评分，返回 `List[CandidateRecord]` |
| `_build_batch(...)` | 构造包含 `sequence`、`ptm_mask`、`ptm_types`、`ptm_positions` 的字典 |
| `_predict(...)` | 运行模型并提取目标类别概率 |

### 2.4 输出字段

`CandidateRecord` 包含：

| 字段 | 含义 |
|------|------|
| `sample_id` / `protein_id` | 样本与蛋白标识 |
| `ptm_type` / `ptm_position` | PTM 类型与位点位置 |
| `baseline_probability` | 完整输入下的目标类别概率 |
| `perturbed_probability` | 掩码后的目标类别概率 |
| `delta_probability` | 概率下降值（重要性得分） |

## 3. TwoStageExplanationPipeline：两阶段筛选与解释

### 3.1 实现位置

- `src/evaluation/explainers.py::TwoStageExplanationPipeline`
- 运行脚本：`scripts/run_two_stage_explanation.py`
- 配置：`configs/integration/two_stage_explanation.yaml`

### 3.2 阶段划分

| 阶段 | 模块 | 任务 |
|------|------|------|
| **Stage 1** | `LeaveOnePTMOutScorer` | 对输入样本的 PTM 位点进行重要性评分并排序 |
| **Stage 2** | `GenKIAdapter` + `ProteinGeneMapper` | 将 Top-K 候选位点映射为基因符号，执行基因扰动解释 |

### 3.3 Stage 2 详细流程

1. **基因映射**：通过 `ProteinGeneMapper.map_candidate(candidate)` 将蛋白-位点映射为基因符号。
2. **构建扰动请求**：`GenKIAdapter.build_request(gene_symbol, mode, magnitude)`。
3. **执行扰动**：调用 GenKI 后端（`hard_ko` 或 `soft_ptm`）得到 `PerturbationResult`。
4. **结果聚合**：
   - `gene_rankings.csv`：所有受影响基因的排名与 p-value。
   - `significant_gene_rankings.csv`：显著性基因子集。
   - `gsea_rankings.tsv`：GSEA 排序结果。
   - `genki_explanations.json`：完整解释记录。
   - `two_stage_summary.json` / `two_stage_summary.md`：摘要报告。

### 3.4 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `top_k_candidates` | 1 | 每样本进入 Stage 2 的候选位点数 |
| `perturbation_mode` | `"hard_ko"` | 扰动模式：`hard_ko` 或 `soft_ptm` |

## 4. SignalingNetworkMapper：信号网络与通路映射

### 4.1 实现位置

- `src/models/signaling_network.py::SignalingNetworkMapper`

### 4.2 内置信号通路

| 通路 | 关键激酶/底物 | 相关 PTM | 输出基因 |
|------|---------------|----------|----------|
| MAPK/ERK | BRAF、RAF1、MAP2K1/2、MAPK1/3 | Phosphorylation | FOS、JUN、MYC、EGR1 |
| PI3K/AKT | PIK3CA、AKT1/2、MTOR | Phosphorylation | FOXO1/3、S6K、4EBP1 |
| JAK/STAT | JAK1/2/3、TYK2、STAT1/3/5 | Phosphorylation | SOCS1/3、IRF1/9 |
| NF-κB | IKBKB、NFKBIA、RELA | Phosphorylation、Ubiquitination | TNF、IL6、IL8、CXCL10 |
| Wnt/β-catenin | GSK3B、CTNNB1、APC | Phosphorylation、Ubiquitination | MYC、CCND1、AXIN2、LEF1 |
| Cell Cycle | CDK1/2/4/6、RB1、TP53 | Phosphorylation、Ubiquitination | E2F1/2、CDKN1A/B |
| Apoptosis | CASP3/8/9、BCL2、BAX | Phosphorylation、Ubiquitination | BCL2L11、PMAIP1、BBC3 |
| DNA Damage | ATM、ATR、CHEK1/2、TP53 | Phosphorylation、Ubiquitination、Sumoylation | CDKN1A、GADD45A、BAX |

### 4.3 扩展能力

- **KEGG 集成**：`pathway_db_path="kegg"` 时通过 `sspa` 加载 KEGG 通路。
- **Reactome 集成**：`pathway_db_path="reactome"` 时加载 Reactome 通路。
- **双库同时加载**：`pathway_db_path="both"`。
- **缓存回退**：网络或依赖不可用时自动回退到内置通路并发出警告。

## 5. PTMDirectionMapper：PTM 到 DAVF 扰动方向映射

### 5.1 实现位置

- `src/models/ptm_direction_mapper.py::PTMDirectionMapper`

### 5.2 方向编码

PTM 类型被映射为 DAVF / BiPerturbEncoder 可识别的扰动方向：

| 方向码 | 方向 | 效应 | 典型 PTM 示例 |
|--------|------|------|---------------|
| 0 | KO（Knockout） | -1 | ubiquitination（促进降解） |
| 1 | KD（Knockdown） | -0.5 | sumoylation（部分抑制）、malonylation |
| 2 | OE（Overexpression） | +1 | phosphorylation（激活信号）、acetylation |

### 5.3 核心机制

1. **静态方向表**：`PTM_DIRECTION_MAP` 覆盖 26+ 种 PTM 类型。
2. **通路上下文覆盖**：`PTM_PATHWAY_CONTEXT_OVERRIDES` 支持按通路关键词调整方向（如染色质相关甲基化为 KD）。
3. **运行时扩展**：`register_ptm_direction()` 与 `register_pathway_context_override()` 允许插件或配置动态注册新类型。
4. **输出张量**：`PTMDirectionMapperOutput` 提供 `gene_ids`、`directions`、`attention_mask`，可直接输入 `BiPerturbEncoder`。

## 6. PTM 虚拟扰动（PTM-aware Virtual Perturbation）

### 6.1 实现位置

- `src/integration/ptm_virtual_perturbation.py::apply_soft_perturbation`
- 运行脚本：`scripts/run_ptm_virtual_perturbation.py`
- 配置：`configs/integration/ptm_virtual_perturbation.yaml`

### 6.2 软扰动 vs 硬敲除

| 扰动模式 | 实现方式 | 用途 |
|----------|----------|------|
| `hard_ko` | GenKI 标准基因敲除模拟 | 对照基线 |
| `soft_ptm` | `apply_soft_perturbation` 调整目标基因表达与边权重 | 模拟 PTM 导致的渐进式调控 |

### 6.3 `apply_soft_perturbation` 公式

给定基因表达矩阵 `counts`、邻接矩阵 `net` 与 `PTMPerturbationProfile`：

```text
counts_new[:, target] = counts[:, target] * node_decay
net_new[:, target]    = net[:, target] * edge_scale
net_new[target, :]    = net[target, :] * edge_scale
```

- `node_decay`：模拟目标基因表达量的衰减或增强（<1 为抑制，>1 为激活）。
- `edge_scale`：模拟目标基因在调控网络中连接强度的变化。

### 6.4 脚本输出

`scripts/run_ptm_virtual_perturbation.py` 对指定基因同时运行 `hard_ko` 与 `soft_ptm`，输出：

- `hard_ko_results.json` / `soft_ptm_results.json`
- `backend_info.json`
- `gene_rankings.csv` / `significant_genes.csv`
- `gsea_rankings.tsv`
- `comparison_summary.json` / `comparison_summary.md`

## 8. 结论

PTM2CellNet 的可解释性体系覆盖“局部位点重要性 → 基因级扰动解释 → 通路级功能映射 → DAVF 扰动方向 → 软硬扰动对比”五个层次：

1. `LeaveOnePTMOutScorer` 提供**样本内 PTM 位点级归因**。
2. `TwoStageExplanationPipeline` 将位点重要性扩展为**基因扰动解释**。
3. `SignalingNetworkMapper` 连接 PTM 变化与**已知信号通路**。
4. `PTMDirectionMapper` 把生物学 PTM 类型翻译为**模型可计算的扰动方向**。
5. `apply_soft_perturbation` 支持**PTM 感知的软扰动**，可与硬敲除形成对照。

该体系为后续“哪些 PTM 位点驱动细胞状态变化”以及“PTM 如何通过基因网络发挥作用”两类问题提供了完整的分析路径。
