### A2: 预训练模型尺寸解析修复 ✅

**问题描述**:
- encoder_type.lower()后尺寸字符串变为小写（如"8m"）
- 与MODEL_NAMES的大写键（如"8M"）不匹配
- 导致模型回退到默认150M

**修复文件**:
- `src/models/pretrained_encoders.py`

**修复内容**:
```python
@staticmethod
def _normalize_model_size(model_size: str) -> str:
    """标准化模型尺寸（大小写无关）"""
    normalized = model_size.upper().rstrip("B")
    return normalized
```

**验证结果**: ✅ 通过
- "150m" → "150M" ✅
- "8M" → "8M" ✅
- "650MB" → "650M" ✅

### A3: 预训练路径维度对齐 ✅

**问题描述**:
- 预训练编码器（ESM-2）的hidden_dim与配置embed_dim不一致
- PTMModule和predictor使用错误的embed_dim初始化

**修复文件**:
- `src/models/architectures.py` (第99-112行)

**修复内容**:
```python
# 使用self.embed_dim确保维度一致
self.ptm_module = PTMModule(
    embed_dim=self.embed_dim,  # 原为 embed_dim
    ...
)
self.predictor = ClassificationPredictor(
    input_dim=self.embed_dim,  # 原为 embed_dim
    hidden_dims=[self.embed_dim * 2, self.embed_dim],
    ...
)
```

**验证结果**: ✅ 通过 - PTMModule与predictor维度一致
