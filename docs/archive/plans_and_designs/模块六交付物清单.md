## 核心功能模块

### 1. train.py - 训练脚本

#### 功能概述
- 整合数据加载、模型创建、训练流程的主脚本
- 支持命令行参数配置
- 自动保存最佳模型和训练曲线

#### 命令行参数
| 参数 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| --config | str | configs/default.yaml | 配置文件路径 |
| --data | str | None | 训练数据路径 |
| --output | str | outputs | 输出目录 |
| --epochs | int | None | 训练轮数 |
| --batch_size | int | None | 批次大小 |
| --lr | float | None | 学习率 |

#### 核心流程
1. **加载数据**: 从CSV或生成示例数据
2. **数据预处理**: 清洗、标准化、划分数据集
3. **创建模型**: PTM2CellNet模型
4. **配置训练器**: 损失函数、优化器、回调
5. **训练**: 执行训练循环
6. **可视化**: 绘制训练曲线
7. **评估**: 在测试集上评估

#### 关键回调
- **ModelCheckpoint**: 保存最佳模型
- **EarlyStopping**: 早停机制

### 2. predict.py - 预测脚本

#### 功能概述
- 使用训练好的模型进行预测
- 支持单样本预测和批量预测
- 支持命令行参数配置

#### 命令行参数
| 参数 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| --model | str | outputs/models/best_model.pt | 模型权重路径 |
| --config | str | configs/default.yaml | 配置文件路径 |
| --input | str | None | 输入数据路径（CSV） |
| --sequence | str | None | 单个蛋白质序列 |
| --output | str | outputs/results/predictions.csv | 输出路径 |
| --device | str | None | 设备（cuda/cpu） |

#### 核心功能
1. **单样本预测**: 直接从命令行输入序列
2. **批量预测**: 从CSV文件读取多个样本
3. **结果输出**: 保存预测结果到CSV

#### 输出格式
- **单样本**: 控制台输出预测结果
- **批量**: CSV文件，包含id、sequence、predicted_cell_state、confidence

### 3. evaluate.py - 评估脚本

#### 功能概述
- 评估训练好的模型性能
- 计算完整的评估指标
- 生成可视化图表

#### 命令行参数
| 参数 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| --model | str | outputs/models/best_model.pt | 模型权重路径 |
| --config | str | configs/default.yaml | 配置文件路径 |
| --data | str | None | 评估数据路径 |
| --output | str | outputs/results | 输出目录 |
| --device | str | None | 设备（cuda/cpu） |

#### 核心功能
1. **加载模型和数据**
2. **计算评估指标**:
   - Accuracy
   - Precision (micro/macro/weighted)
   - Recall (micro/macro/weighted)
   - F1 (micro/macro/weighted)
   - AUC-ROC
   - AUC-PR
3. **生成可视化图表**:
   - ROC曲线
   - PR曲线
   - 混淆矩阵

#### 输出文件
- **evaluation_metrics.json**: 评估指标JSON
- **roc_curve.png**: ROC曲线
- **pr_curve.png**: PR曲线
- **confusion_matrix.png**: 混淆矩阵

## 使用示例

### 训练模型
```bash
python scripts/train.py --config configs/default.yaml --epochs 50 --batch_size 32
```

### 单样本预测
```bash
python scripts/predict.py --sequence "ACDEFGHIKLMNPQRSTVWY"
```

### 批量预测
```bash
python scripts/predict.py --input data/processed/test.csv --output outputs/results/predictions.csv
```

### 评估模型
```bash
python scripts/evaluate.py --model outputs/models/best_model.pt --output outputs/results
```
