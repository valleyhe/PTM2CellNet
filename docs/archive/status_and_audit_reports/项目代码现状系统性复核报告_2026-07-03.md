## 3. 未完全实现的功能及完成度

### 3.1 `DAVFInferenceModule` — 完成度约 85%

**已实现**：`scvi_latent` / `gene` 双模式、`GeneMLEPEncoder`、`DeltaProjection`、freeze/unfreeze、优雅降级（零特征回退）、`GeneMLEPEncoder` 无外部 checkpoint 需求。

**缺失 / 问题**：
1. `state_space="gene"` 模式下，`_load_checkpoint()` 直接设置 `_checkpoint_loaded=True` 跳过了所有检查点逻辑。如果未来添加检查点，此路径需要重构。
2. `DeltaPredictor` 检查点加载未在 `gene` 模式测试。
3. `forward()` 的 `z_0` 参数声明但仅在 `scvi_latent` 模式被消费。

**引用**：`src/models/davf_inference.py:219-457`

### 3.2 `PTM2CellNet` DAVF 分支 — 完成度约 80%

**已实现**：`use_davf` 开关、配置合并、predictor 输入维度扩展、零特征降级（D-18）。

**缺失 / 问题**：
1. DAVF batch key 命名与 `preprocess_request` 输出不兼容：代码期望 `davf_sites` / `davf_gene_names`，但 API 预处理只产出 `sequence` / `ptm_mask` / `ptm_types`。
2. `PTMDirectionMapper` 在 `__init__` 中无参构造（`src/models/architectures.py:589`），会立即初始化 Geneformer loader 和 `GeneMapper`，拖慢模型构建。
3. 未消费 `configs/davf_integration.yaml` 中的 `ptm_mapper.max_targets` (32) 和 `integration.*` 字段。

**引用**：`src/models/architectures.py:564-609`

### 3.3 `MambaEncoder` — 完成度约 60%

**已实现**：`MambaBlock`、`SelectiveSSM`、嵌入层、mask 处理、12 个测试通过。

**缺失**：`_ssm_step` 使用纯 Python `for t in range(seq_len)` 串行递推，无 CUDA 并行 / scan 优化。

**引用**：`src/models/mamba_encoder.py:164-174`

### 3.4 `ModelCheckpoint` — 完成度约 75%

**已实现**：`monitor`、`mode`、`save_best_only`、`save_last`、`verbose`。

**缺失**：
1. 不保存完整 checkpoint（优化器 / scheduler / epoch 状态）。
2. `save_last` 文件名生成脆弱：`.replace(".pt", "_last.pt")`。
3. 不支持 `save_top_k > 1`。

**引用**：`src/training/callbacks.py:53-136`

### 3.5 `cross_validate` — 完成度约 30%

**已实现**：基本交叉验证循环。

**缺失 / 问题**：
1. 0 个测试覆盖。
2. `train_fn=None` 默认行为仅为评估，非标准交叉验证。
3. 回调用法、折叠索引等无文档。

**引用**：`src/evaluation/evaluators.py:170`

### 3.6 排序指标与置信区间 — 完成度约 50%

**已实现**：`calculate_ndcg`、`calculate_map`、`calculate_ranking_metrics`、`calculate_bootstrap_ci`、`calculate_metric_ci`、`calculate_cross_validation_ci` 函数定义。

### 3.7 `TwoStageExplanationPipeline` — 完成度约 40%

**已实现**：两阶段筛选与解释框架、GenKI 后端集成。

**缺失**：0 个单元测试覆盖。

**引用**：`src/evaluation/explainers.py:173-269`

### 3.8 `SignalingNetworkMapper` 核心逻辑 — 完成度约 50%

**已实现**：8 条内置通路、KEGG / Reactome 集成、下游基因预测。34 个测试（含 KEGG 集成测试和扩展通路测试）全部通过。

## 8. 综合性结论

### 优势
1. **测试体系健壮**：1196 个单元测试全部通过，覆盖了核心数据处理、模型构建、训练循环、评估指标、API 路由、DAVF 流水线、GenKI 集成等关键路径。
2. **大量遗留问题已修复**：自 07-02 报告以来，18+ 个标记问题得到解决，包括编码器三重定义、依赖拆分、PTMDataModule 命名冲突等严重阻碍。
3. **架构扩展良好**：DAVF 双模式支持（`scvi_latent` + `gene`）、GeneMLEPEncoder、DeltaPredictor、PEFT/LoRA、GenKI 集成等新功能集成有序。

### 关键短板
1. **依赖管理盲区**：`torchmetrics` 缺失导致 `requirements-core.txt` 环境导入 evaluation 模块即失败。
2. **集成测试红线**：BRaf V600E 变体工作流 4 个失败反映核心生物学分析管线数据流断裂。
3. **DAVF 孤岛**：模型层 DAVF 架构完整，但 API 层和 `preprocess_request` 完全不支持 —— 导致 DAVF 功能无法通过 API 使用。
4. **mypy 覆盖缺口**：10 个文件禁用类型检查，在架构类和 API 路由中尤为突出。
5. **文档与代码脱节**：`AGENTS.md` 仍只覆盖约 10% 实际代码。
