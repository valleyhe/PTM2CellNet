## 3. 技术债

### 3.1 代码质量问题

#### 3.1.1 编码器重复定义（严重: 高）

| 位置 | 重复内容 | 构造器差异 |
|------|----------|-----------|
| `src/models/encoders.py` | `CNNEncoder`, `TransformerEncoder`, `LSTMEncoder` | `(vocab_size, embed_dim)` |
| `src/models/multitask_ptm.py:258-331` | `CNNEncoder`, `TransformerEncoder`, `LSTMEncoder` | `(embed_dim, hidden_dim)` |
| `src/models/ptm_site_predictor.py:146-244` | `CNNEncoder`, `TransformerEncoder`, `LSTMEncoder` | `(embed_dim, hidden_dim)` |

三个文件各自定义了同名编码器，构造器签名不同，导致 import 歧义和维护风险。

#### 3.1.2 mypy 类型检查被全局禁用

| 文件 | 禁用方式 |
|------|----------|
| `encoders.py:1` | `# mypy: ignore-errors` |
| `architectures.py:1` | `# mypy: ignore-errors` |
| `pooling.py:1` | `# mypy: ignore-errors` |
| `model_utils.py:1` | `# mypy: ignore-errors` |
| `long_sequence.py:1` | `# mypy: ignore-errors` |
| `multitask_ptm.py:1` | `# mypy: ignore-errors` |
| `routes/predictions.py:1` | `# mypy: ignore-errors` |
| `routes/state.py:1` | `# mypy: ignore-errors` |
| `multitask.py:6` | `# mypy: disable-error-code` |
| `ptm_site_predictor.py:6` | `# mypy: disable-error-code` |
| `signaling_network.py:6` | `# mypy: disable-error-code` |
| `variant_effect.py:6` | `# mypy: disable-error-code` |
| `peft_config.py:12` | `# mypy: disable-error-code` |
| `multitask_dataset.py:1` | `# mypy: ignore-errors` |

**总量**: 10 个文件完全禁用 mypy，4 个文件部分禁用。这意味着这些文件的类型安全性完全未验证。

#### 3.1.3 非标准氨基酸映射定义重复（严重: 中）

相同的映射逻辑在三个文件中独立定义：
- `src/data/preprocess.py:46-48` (`NON_STANDARD_AA_MAP`)
- `src/data/datasets.py:58-60` (`non_standard_aa_map`)
- `src/data/datasets.py:295-297` (`non_standard_aa_map`)

#### 3.1.4 `AA_TO_IDX` 字典四处重复定义

- `src/data/features.py:27,54`
- `src/data/multitask_dataset.py:26-32`（类级别）
- `src/data/ptm_site_dataset.py:15-16`（模块级别）

#### 3.1.5 `ProtBERTEncoder` 跳过父类构造函数

`src/models/pretrained_encoders.py:455` 中 `ProtBERTEncoder.__init__` 调用 `nn.Module.__init__(self)` 而非 `PretrainedEncoder.__init__(self)`，手动复制父类的初始化逻辑。若父类初始化逻辑变更，会静默失步。

#### 3.1.6 Mamba SSM 的串行实现

`src/models/mamba_encoder.py:164-174` — `_ssm_step` 使用 `for t in range(seq_len)` 逐时间步迭代，无 CUDA 并行化，长序列性能受限。

#### 3.1.7 可变的模块级常量

`src/data/features.py` 中 `AMINO_ACIDS = DEFAULT_AMINO_ACIDS` 和 `PTM_TYPES = DEFAULT_PTM_TYPES` 是可变列表别名，可能被意外修改。

#### 3.1.8 Geneformer 静默回退到随机嵌入

`src/models/geneformer_embedding.py:224-248` — `_use_fallback()` 在 Geneformer 加载失败时静默创建随机嵌入，仅通过 `UserWarning` 通知，生产环境中可能隐藏严重故障。

#### 3.1.9 绝对导入路径

`src/data/preprocess.py` 和 `src/evaluation/visualization.py` 使用 `from src.utils.logging` 等绝对导入，包的运行方式会决定导入是否成功。

#### 3.1.10 `ModelCheckpoint` 的文件路径替换脆弱

`src/training/callbacks.py:111` 使用 `.replace(".pt", "_last.pt")` 来生成最新检查点文件名，对非 `.pt` 扩展名（如 `.pth`）会静默失败。

#### 3.1.11 `batch_predict` 中的 Pydantic v1/v2 兼容代码

`src/api/routes/predictions.py:75` — 使用 `hasattr(ptm_site, "model_dump")` 检测 Pydantic 版本，但 `ptm_site.dict()`（v1 备选）将在未来版本移除。

#### 3.1.12 `visualization.py` 的模块级后端切换

`src/evaluation/visualization.py:19` — `plt.switch_backend("Agg")` 在模块导入时执行，阻止了交互式使用。

#### 3.1.13 `compute_sample_weights` 与 `compute_class_weights` 功能重叠

`src/data/augmentation.py` 和 `src/data/dataset_base.py` 都实现了相似的类别权重计算逻辑，可统一。

#### 3.1.14 梯度计算中丢弃损失

`src/training/losses.py:50` (`FocalLoss.forward`) — 在计算 `pt` 时使用了 `logits.detach()` 来获取 `targets` 但未在之前保留图。`alpha_t = alpha.gather(...)` 也可能从参数张量断开图。

#### 3.1.15 `inplace` 操作与图构建

`src/training/losses.py:68` — `probs.clamp(min=eps, max=1-eps)` 使用 `inplace`，可能在多处使用同一张量时导致图构建问题。
