本轮以 v15 列出的 8 个 F-* 功能项与 3 个 TD-H、5 个 TD-M、3 个 TD-L 技术债为输入，完成 3 轮迭代后得到下列可复核结论：

2. **真实资产验收层（TD-H2 / F-01 / F-02 / F-04 / F-05）**：新增 `tests/real_assets/` 选择性运行套件，统一以 `PTM2CELLNET_RUN_REAL_ASSET_TESTS=1` 门控，覆盖 ESM-3 真实权重加载、DAVF E2E subprocess、分布式 DDP、UniProt / KEGG 联网。每个测试在 `outputs/real_assets/<test>.json` 落盘证据（host / 来源 / 耗时 / 形状 / 失败原因），使「我们真的跑过真实资源」可审计而非默认 CI 的隐含承诺。默认 CI 全部 skip（6 项），不破坏既有流水线。
3. **生产安全 fail-fast（TD-M3 / TD-M4 / 安全 §6）**：新增 `src/api/production_security.py`，在 `PTM2CELLNET_ENV=production` 下：未配置 `PTM2CELLNET_API_KEY` 或将 `PTM2CELLNET_DOWNLOAD_ALLOWLIST` 显式置空时，默认拒绝启动；提供三级 opt-out（`PTM2CELLNET_ALLOW_INSECURE_PROD` / `..._UNAUTHED_PROD` / `..._UNRESTRICTED_DOWNLOADS`）支持「带 warning 启动 + /ready 503 降级」。`scripts/train.py` 的 resume 路径改为走 `safe_torch_load`，统一审计与全局 `PTM2CELLNET_SAFE_LOAD_ONLY`。
4. **CPTAC 验证生产化路径（F-03 / TD-H3）**：新增 `src/analysis/pdc_client.py`（真实 PDC GraphQL，纯网络 I/O，单测用假 session 覆盖 query / 解析 / 错误路径）；`scripts/validate_cptac.py` 重构为默认走 PDC，mock 数据显式收到 `--mock` flag 后面，所有结果文件强制 `scientifically_valid=false`，杜绝「mock 结果被当成真实验证」。
5. **架构 / 类型债（TD-M1 / TD-L1）**：根目录 `signaling_network.py` 通过 identity-equality 单测锁定为 re-export shim；`src/integration/genki_adapter.py` 的唯一一处 `type: ignore[assignment]` 用 `cast` 消除；`src/training/peft_config.py` 改 `Literal` 类型后达到完全类型干净，对应 `pyproject.toml` 的 mypy override 被删除（11 → 10）。
6. **依赖与文档对齐（TD-M5 / F-07 / F-08）**：`docs/guides/installation.md` 增加 `requirements-*.txt` 能力映射表与「为什么 anndata/sspa/lion-pytorch 不在 core」FAQ；F-07 Lightning logger 一致性通过 paren-balance 源码扫描测试固化；F-08 FastAPI lifespan 迁移决策写入注释。
