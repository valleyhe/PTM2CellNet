PTM2CellNet Documentation
=========================

PTM2CellNet is a deep learning framework for predicting cell-type-specific
responses to post-translational modifications (PTMs). It integrates protein
language model embeddings with graph neural networks to model PTM-driven
perturbations at single-cell resolution.
