| ID | 问题 | 严重程度 | 说明 |

#### 3.4.2 解决策略详细方案

**SEC-01：预测端点认证**
```
方案：
1. 在 `app.py` 中添加可选 API key 中间件 `_OptionalAuthMiddleware`
2. 中间件从 `X-API-Key` 头读取，与 `PTM2CELLNET_API_KEY` 环境变量比较
3. 如果环境变量未设置，跳过认证（向后兼容）
4. 如果设置且请求未携带有效 key，返回 401
5. 对 `GET /health /live /ready` 豁免认证
文件影响：`src/api/app.py`（新增中间件）、`src/api/routes/predictions.py`（无变化）
工作量：约 40 行 Python，30 分钟
```

**SEC-02：safe_torch_load 加固**
```
方案：
1. 将 `safe_torch_load` 的 `enforce_safe_only` 默认值改为 `True`
2. 在 `load_model()` 调用时显式传递 `enforce_safe_only=True`
3. 在 `davf_inference.py:_load_checkpoint` 中使用 `enforce_safe_only=True`
4. 添加日志以指导使用 `safetensors` 格式替换 pickle

```
