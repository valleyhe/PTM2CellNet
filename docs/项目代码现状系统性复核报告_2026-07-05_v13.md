## 7. 建议解决路线

### P0：静态门禁恢复

目标：`mypy src` 降到 0 errors，不重新引入 `mypy: ignore-errors`。

1. 确认 CI/type-check job 安装 `requirements-dev.txt` 或包含 `types-requests`、`types-PyYAML` 的依赖集。
2. 清理 unused ignore：`src/integration/genki/reference_data.py`、`src/models/external_tools/base.py`、`src/models/pretrained_encoders.py`、`src/api/app.py`。
3. 修复 `src/api/middleware.py` 两个返回 Any，显式 `str(...)` 或收窄 header/query 类型。
4. 为 `SlidingWindowHandler` 的 encoder 参数定义 Protocol：`parameters()`、`tokenize()`、`hidden_dim`、`__call__()`。
5. 修复 `src/evaluation/visualization.py` 的 `set_xlim` / `set_ylim` 参数为 tuple。
6. 收敛 GenKI sparse matrix 类型，避免 ndarray/scipy sparse union 误判。

### P1：ESM-3 生产闭环

1. 将 `esm3_sm_open` 加入 `scripts/train_pretrained.py::PRETRAINED_MODELS`。
2. 在 `requirements-pretrained.txt` 声明 EvolutionaryScale `esm` 依赖或提供官方安装说明。
3. 新增 mock CLI smoke：`python scripts/train_pretrained.py --model esm3_sm_open ...` 不真实下载权重，但验证配置路径、encoder_type、artifact manifest。
4. 新增 strict asset 手动/可选测试：本地缓存存在时跑一条极短 ESM3 forward；缓存不存在时 strict 明确失败。

### P2：DAVF E2E 决策

若保留实验状态：迁移到 `scripts/experimental/finetune_davf_e2e.py`，正式文档只说明实验性质。  
若转正：删除 placeholder head，接入正式 Dataset/DataModule、任务 schema、artifact manifest、最小 1 epoch subprocess 测试。

### P3：文档治理

1. 新增 `docs/CURRENT_STATUS.md` 指向本报告。
2. 对 v12 以前系统复核报告批量加历史快照提示。
3. README / quickstart 明确当前支持面：CLI、Python API、FastAPI；GUI/实时流/自定义 PTM DB 已取消。
