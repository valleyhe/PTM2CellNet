## 四、技术债分类与评估

### 4.1 代码质量问题

#### 4.1.1 🔴 高 — `mypy: ignore-errors` 文件（6 个）

| 文件 | 禁用代码行数 | 原因 |
|------|-------------|------|
| `src/data/ptm_site_dataset.py` | 6 | 动态属性 / Lightning 复杂类型 |
| `src/data/loaders.py` | 4 | 动态加载器分发 |
| `src/models/davf.py` | 3 | DAVF 复杂条件逻辑 |
| `src/models/external_tools.py` | 2 | 外部工具子进程 |
| `src/api/app.py` | 2 | FastAPI 路由类型 |
| `src/integration/genki_adapter.py` | 2 | 可选依赖防护 |

**影响**: 中 — 类型安全检查被跳过，重构时可能引入类型错误。
**建议**: 逐文件渐进修复，从 `ptm_site_dataset.py` 开始。

#### 4.1.2 🔴 高 — 超大文件（>800 行）

| 文件 | 行数 | 风险 |
|------|------|------|
| `src/models/davf.py` | **1000** | 重构候选：`DAVF` 主类 + `DAVFLoss` + `DirectionConsistencyLoss` |
| `src/data/loaders.py` | **936** | 6 个加载器合并在一个文件中 |
| `src/api/app.py` | **913** | FastAPI 应用工厂 + 全部路由注册 + 中间件 |
| `src/data/homology_splitter.py` | **902** | 同源拆分 + 稀疏向量化 |
| `src/utils/io.py` | **836** | 全部 IO 操作 + SafeUnpickler + 模型加载 |
| `src/models/external_tools.py` | **836** | AlphaFold/BLAST/ClustalW/PSIPRED 客户端 |

**建议**: 优先拆 `davf.py`（编码器 → `davf_encoder.py`），其余监控增长趋势。

#### 4.1.3 🟡 中 — Mamba SSM 串行实现

| 属性 | 内容 |
|------|------|
| **文件** | `src/models/mamba_encoder.py` |
| **问题** | `SelectiveSSM._ssm_step()` (L123-207) 使用 Python for 循环实现 SSM 递推，未使用 fused CUDA selective-scan kernel |
| **影响** | 训练速度远低于官方 Mamba 实现；仅 CPU 可用时更明显 |
| **备注** | 已有文档注释说明 "a fused CUDA selective-scan kernel would be needed to eliminate the Python loop" |

#### 4.1.4 🟡 中 — 长序列窗口逻辑重复

| 属性 | 内容 |
|------|------|
| **文件** | 散见于 `src/models/` |
| **问题** | 长序列拆窗、滑动窗口、重叠窗口的逻辑在 `encoders.py`、`long_sequence.py`、`pretrained_encoders.py` 中有重复实现 |
| **建议** | 提取公用窗口工具函数到 `src/utils/sequence_utils.py` |

## 七、结论

### 核心结论

1. **无阻塞性未实现功能** — AGENTS.md 设计蓝图中的所有类/方法均已实现，实际代码比蓝图更丰富。
2. **代码质量健康** — 0 个 TODO/FIXME/HACK，0 个 `shell=True`，0 个 `eval()`，0 个硬编码密钥。安全防护完善。
3. **测试覆盖率高** — 114 个测试文件覆盖 84 个源文件，~1433 测试全部通过。
4. **主要技术债聚焦在文件大小和类型检查** — `davf.py` (1000 行) 和 6 个 mypy 禁用文件是需要优先关注的两项。
5. **已知性能债** — Mamba SSM 串行实现（Python loop）和长序列窗口逻辑重复有文档记录但未解决。

### 建议优先行动项
