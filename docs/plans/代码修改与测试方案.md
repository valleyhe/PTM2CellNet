### 3.3 数据预处理修复 (P1-4)

**问题**: 2,018条记录(2.51%)含U(硒代半胱氨酸)和X(未知)字符。

**修改计划**:

#### 修改 src/data/preprocess.py
```python
class DataPreprocessor:
    # 新增方法
    def standardize_amino_acids(self, df: pd.DataFrame,
                                 sequence_col: str = "sequence") -> pd.DataFrame:
        """
        将非标准氨基酸字符映射为标准字符
        
        映射规则:
            U (selenocysteine) → C (cysteine, 生化性质最接近)
            X (unknown) → A (alanine, 最常见氨基酸)
            J (leucine/isoleucine) → L (leucine)
            B (asx) → D (aspartic acid)
            Z (glx) → E (glutamic acid)
        """
        mapping = {
            'U': 'C', 'X': 'A', 'J': 'L', 'B': 'D', 'Z': 'E',
            'O': 'K',  # Pyrrolysine → Lysine
        }
        df = df.copy()
        for old, new in mapping.items():
            df[sequence_col] = df[sequence_col].str.replace(old, new, regex=False)
        return df
```

#### 修改 src/data/datasets.py (PTMDataset)
```python
def __getitem__(self, idx: int) -> Dict[str, torch.Tensor]:
    # 在编码前做字符验证

        # 自动修复而非直接报错
        sequence = self._standardize_sequence(sequence)
    ...
```
