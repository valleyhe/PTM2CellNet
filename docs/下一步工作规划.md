### 优先级3：高级功能开发（中期）

#### 3.1 门控PTM融合（方案D）
**目标**: 实现更高级的PTM-序列融合机制

**设计**:
```python
class GatedPTMFusion(nn.Module):
    """门控PTM融合"""
    def forward(self, seq_emb, ptm_emb):
        gate = sigmoid(W_g @ [seq_emb; ptm_emb])
        return gate * seq_emb + (1 - gate) * ptm_emb
```

**任务**:
- [ ] 实现GatedPTMFusion模块
- [ ] 集成到MambaEncoder
- [ ] 对比简单融合vs门控融合
- [ ] 可视化门控权重

**预计时间**: 3-4天
